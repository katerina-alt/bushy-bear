# SNS 90-Day Restructuring Dashboard

Waddle Bear Media executive decision page for the SNS direct-to-consumer business:
lean operating model, conditional affiliate offer retention (Moringa, Berberine,
Turmeric, Complete Thyroid), the December 1 customer support handoff to Rose, and
Jan–Sep 2026 SNS P&L evidence.

Open `index.html` in any browser. It is a single self-contained file; fonts
(Cormorant Garamond / Inter) load from Google Fonts and fall back to Georgia /
system fonts offline. Checklist ticks are saved in the viewer's browser only.

Styled to match the Wine & Drama dashboards, in a blue palette, with light and
dark themes.
